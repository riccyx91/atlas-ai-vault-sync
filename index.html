ATLAS AI Vault Sync

A personal desktop utility for keeping selected local files in sync with the operator’s Google Drive using rclone.

How it works

The operator authorizes rclone through Google’s OAuth sign-in. rclone runs on the operator’s computer and uses the Google Drive API to carry out the file operations configured for the sync. This public information site has no sign-in form or connection to Google Drive.

Read the privacy policy for details about Google Drive data, local credentials and revoking access.
